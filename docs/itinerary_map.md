# 旅程地図

旅程作成画面では観光地の並び順に1から番号を表示する。出発地・到着地は番号を使わない。
現在の旅程モデルは出発地に帰着するため、到着地は出発地と同じ座標になる。
同じ座標の出発地・到着地は `出発・到着`、観光地は `1・2` のように1つのピンにまとめる。
削除・並べ替え時は現在の観光地リストから再採番し、ラベルが変わればピンのキーも更新する。
ツールチップには番号・名称・住所を表示する。

隣接する訪問地点を直線の点線で結び、進行方向の矢印を付ける。
往路・復路が同じ線になる場合にも方向が読めるよう、矢印は各区間の65%の位置に置く。
道路経路や運行経路の表示ではない。ゼロ距離の区間は線を描かない。
座標未設定・不正座標の訪問にはピンを描かず、番号を案内する。
その訪問を飛ばした接続線は描かない。

訪問順の並べ替えではカメラ位置・倍率を維持し、番号と接続線だけを更新する。
同じ座標にまとめられたピンの番号が変わっても自動調整しない。
初期表示・地点の追加や削除・座標変更・地図サイズ変更・旅程パネルの高さ変更では、
パネルに隠れない地図の幅・高さの各10%を余白とし、残る80%以内にピンが収まるよう調整する。
ピン自体の幅・高さも余白に含める。地図がほぼ完全に隠れている間は調整を待つ。
手動で地図を動かした後は「旅程全体を表示」で再調整できる。

`test/itinerary_map_test.dart` で、最新カタログの座標、番号・重複座標・位置未設定の扱い、
点線区間、並べ替え、画面リサイズ、パネルに隠れない80%の範囲、全体表示ボタンを検証する。
旅程編集・出発地・徒歩・交通時刻表を含む関連20件のテストと静的解析は通過済み。
